# Crown & Co. — بوتيك الساعات الفاخرة ثلاثي الأبعاد

متجر عرض تجريبي (Concept Demo) لساعات فاخرة مع **أتيليه 3D إجرائي بالكامل** — بناء الساعات يحدث برمجيًا في المتصفح (three.js) بلا أي ملفات نماذج خارجية. عربي/إنجليزي كامل + RTL + 4 عملات.

## 📁 بنية المشروع

| الملف | الدور |
|---|---|
| `index.html` | **المنتج النهائي** — ملف واحد مكتفٍ ذاتيًا (CSS + JS مضمّنان). افتحه مباشرة بأي متصفح، أو انشره كـ static كما هو. |
| `index.src.html` | القالب المصدر (HTML فقط + `<link>` للأنماط + `<script src>` للسكربت + وسوم CDN). |
| `styles.css` | كامل التنسيقات (مصدر التعديل). |
| `app.js` | كامل منطق التطبيق (مصدر التعديل): البيانات، i18n، السلة، المُهيّئ، محرك 3D، الحركة. |
| `build.ps1` | يدمج `styles.css` + `app.js` داخل `index.src.html` → ينتج `index.html`. **شغّله بعد أي تعديل على المصادر.** |
| `server.js` | سيرفر ثابت مبدئي اختياري للمعاينة عبر HTTP: `node server.js` ثم `http://localhost:8727` |
| `archive/` | النسخ الأصلية المحفوظة (index-original.html + تقسيم p1–p5 القديم + _main.js). **محفوظة للرجوع فقط — لا تُعدل ولا تُشحن** |

## ▶️ التشغيل

```powershell
# الطريقة 1: مباشرة
start index.html

# الطريقة 2: سيرفر محلي (مستقر للاختبار)
node server.js      # ← ثم افتح http://localhost:8727

# الطريقة 3: بعد تعديل المصادر — أعد البناء
powershell -ExecutionPolicy Bypass -File build.ps1
```

> يتطلب ثلاث مكتبات CDN (three.js + GSAP + ScrollTrigger — محشورة SRI بأمان). **بدون إنترنت تعمل الصفحة بلا عطل** عبر مسار التحلل التصميمي (ساعة CSS بديلة، `no-anim`، عدم إظهار جديد).

## ✅ الإصلاحات والتطويرات المطبقة (دفعة الإصلاح الشاملة)

### أخطاء وظيفية حقيقية
1. **اختفاء بطاقات (شهادات العملاء/البوتيكات) بعد تبديل اللغة** — `observeReveals()` كان no-op؛ أصبح يمرّر الشبكات المعاد رسمها إلى مراقب الظهور المشترك.
2. **خلل تسعير المُهيّئ** — تعيين التكوين الافتراضي كان `bezel:'steel'` بدل `ceramic` فيظهر Submariner بـ $10,850 بدل **$11,250** (عكس بطاقة المجموعة)؛ أصبح مشتقًا ذاتيًا من `modelDefaults()` فلا يحدث انحراف مستقبلًا.
3. عقرب GMT وقت معين +3 ملجمود — الآن **يُدرس بالفعل وقت جينيفا الحقيقي** (Europe/Zurich + DSحر عبر `Intl` مع fallback +3).
4. أدمج قالبين `@media (max-width:1024px)` مكررين في قاعدة واحدة.
5. حذف قاعدة ميتة `html.cur-on html, html.cur-on body{}`.

### أمان
6. **SRI** (SHA-384 محسوبة من التنزيل الفعلي) على كل وسوم CDN الثلاثة + `crossorigin/referrerpolicy`.
7. `esc()` تهوّب الآن علامة التنصيص الفردية أيضًا (حماية سمات).

### i18n / أسعار
8. الأرقام والعملات وفق اللغة: `ar-EG` (أرقام عربية إشارات غير مرادفة) بدل `en-US` الجامد — مثالي: `‏١١٬٢٥٠ US$`.
9. `© السنة` ديناميكية من الساعة وليس 2026 مرسّخةً.
10. `noscript` ثنائي اللغة (سطر عربي إضافي).

### RTL + إمكانية الوصول
11. رابط «التخطي» يشير إلى `#main` الدلالي (مع `tabindex="-1"`) بدل `#collection`.
12. عناوين القصة: `<h2 class="sr-only">` كامل الترجمة يصحح التسلسل الدلالي h2→h3.
13. بيانات الاتصال تعمل: `mailto:` + `tel:` بدل نص خامل.

### UX صدقة
14. أيقونات التواصل الاجتماعي كانت تلقف بالنقل إلى أقسام صفحة عشوائيًا، الآن **toast صديق** («تنتهي قريبًا») عبر `[data-soon]` + `delegation`.
15. إصلاح ألوان مصقلة في الوضع الفاتح: سكرولبار (`var(--bg)` + توكن `--scroll-thumb`)، خيارات العملة `var(--bg-3)`، نص-على-الذهب توكن `--on-gold` في كل مواضع (زر، badge، chip، skip-link، ::selection).
16. خلفية الـ Preloader بالتوكن `var(--bg)` بدل ثابت.
17. preconnect لـ cdnjs + وسوم **Open Graph / Twitter Card** للمشاركة الاجتماعية.
18. خفيفة: سنة إغلاق + أسعار + SRI/`\?fresh` تحقيقات ميدانية متعددة.

## 🔎 ملاحظات ترحيلية (حاجز بيئة الاختبار لا حاجز كود)
- بيئة فحص الاتصال هنا حجبت CDN (لا GSAP/THREE) — الصفحة تحوّلت **بلا عطل** إلى المسار التصميمي (`no-anim`) — هذا تثبيت حي لمسارات التحلل.
- في متصفح فعلي مع إنترنت: GSAP + THREE يعملان كاملًا (مختبر دون دقق فيsandbox لأنه يمنع الشبكة الخارجية).
